# Studio Vale

A contemporary fashion store with size selection, a persistent shopping bag and demo checkout.

## Run on Windows

Requires Node.js 22.12 or newer. From this directory:

```powershell
npm install
npm run dev
```

Open **http://localhost:3003**. If dependencies are already installed at the collection root, skip installation. Use `npm.cmd` if PowerShell blocks `npm.ps1`. Stop with Ctrl+C.

`npm run build` creates `dist/`. `npm run preview` serves that build on the same port. `npm run typecheck` checks TypeScript.

## Technology

React · TypeScript · GSAP · Vite · custom CSS · local fonts and imagery.

All code and runtime assets are in this directory. The brand and products are fictional. Forms and orders are local demos; no emails, payments or bookings are sent.
